# Recursos del aparcamiento panorámico

Los cuatro archivos de esta carpeta se generaron con la herramienta integrada de imágenes de Codex el 24 de agosto de 2026 para el piloto de `PREDATOR N-5.2`.

- `aparcamiento_master.png`: fondo panorámico vacío, lluvia nocturna y tres plazas legibles.
- `vehiculo_utilitario.png`: utilitario civil gastado, fondo transparente.
- `vehiculo_furgoneta.png`: furgoneta de reparto sin marcas, fondo transparente.
- `vehiculo_prototipo_mort.png`: sedán corporativo camuflado como vehículo civil, fondo transparente.

Los vehículos se mantienen como capas independientes para cambiar su estado sin regenerar el fondo. No contienen texto, logotipos ni marcas de obras externas. Los PNG de vehículos conservan alfa real; el fondo maestro es RGB opaco.
